Architecture & Responsible-Use Scope

Pillars of Safe Assistive Mapping

PMIR-Net-Lite is engineered specifically for voice and communication assistance where precision, predictability, and user agency are paramount.

1. Multi-Signal Hybrid Scoring

Leverages Levenshtein distance, content-word weighted token alignment, character n-grams, and pure-Python phonetic Metaphone & Soundex codes to resolve phonetically degraded utterances without cloud dependencies.

2. Strict Human-in-the-Loop Gating

No candidate intent is ever broadcast via Text-To-Speech or entered into vocabulary until the user explicitly confirms or edits the prediction.

3. Additive & Inspectable Personalization

Stores user-confirmed phrase mappings in transparent JSON. Prioritizes user phrasing over base templates with instant priority boosting.

4. Safe Abstention Thresholding

If model confidence falls below \(\tau = 0.52\), the engine abstains from ungrounded guessing and triggers a clarification dialogue.

Verbatim Scope & Ethics Notice:

Assistive prototype only. No clinical or diagnostic claims. No real patient/impaired-speech data without documented informed consent and ethics/IRB approval — use simulated data by default and say so wherever the data is referenced.
